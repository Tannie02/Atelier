# 👗 Outfit Picker — AI/ML Personalized Outfit Recommender

Outfit Picker is an AI-powered smart wardrobe and outfit recommendation platform. It enables you to digitize your wardrobe from smartphone photos, automatically classify clothing items using **CLIP zero-shot classification**, extract dominant color palettes using **K-Means clustering**, and generate intelligent top-to-bottom outfit recommendations tailored to **live real-time weather** and **occasions**.
